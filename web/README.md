# MP web app

The super-admin console and each organization's dashboard (modules M1 to M9), built with Next.js.

```bash
npm ci
MP_API_URL=http://localhost:8080 npm run dev   # http://localhost:3000
```

Checks: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`. Setup, settings, and a demo on made-up data are in [SETUP.md](../SETUP.md#the-web-app).
